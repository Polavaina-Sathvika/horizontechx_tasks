## 📊 Projects

### Task 1 – Sales Analytics Dashboard

Created an interactive Power BI dashboard to analyze sales-related data using KPIs, charts, slicers, filters, and business insights.

### Task 2 – Student Performance Analytics Dashboard

Developed an interactive dashboard to analyze student performance using data modeling, Power Query, DAX measures, relationships, and multiple Power BI visualizations.

Created an interactive Netflix analytics dashboard to analyze movies and TV shows based on revenue, production budget, IMDb ratings, genres, countries, release years, awards, and content type.
